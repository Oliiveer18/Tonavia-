# CONTINUAR · cómo retomar el proyecto (v2.332, 13 nov 2026)

Lee en este orden: este archivo → `CLAUDE.md` (reglas y normas permanentes) → `docs/ROADMAP.md` (estado y lo que queda) → `docs/SESION.md` (sesiones v2.305 en adelante; lo anterior está en `docs/archivo/`).

## Qué es
Juego web de monstruos en pixel art, todo dibujado por código. Un solo archivo (`dist/criaturas.html`, `node build.js`; fuentes en `src/` según `src/orden.json`). Dos jugadores: **Oli** (el usuario) y **Lali**, cada uno desde su móvil (iPhone 14 el de Oli). El 2D es la base; el HD-2D (Three.js) es opción encima. Se prueba como Artifact privado: `criaturas_juego.html` + `ignel_glb.wasm` (el GLB de Ignel; el alojamiento no sirve `.glb`).
